# Validation comparison contract

Use matching fictional project inputs, allowed effects and suitable existing
runtimes for baseline and candidate. The baseline receives the raw task/context;
the candidate additionally receives the selected current validation instructions.

Expected outcomes stay evaluator-only. Observe actual commands, canonical checks,
no-write failures, source/index preservation and unresolved attribution. Equivalent
inputs do not imply equivalent results; record each arm independently. Missing
runtime or authority blocks the affected observation. Matched actor/performance
trials require the approved protocol and actual accounting.

Every recorded result is scoped to its input identities. Fixture execution,
metadata integrity, model adherence and publication approval are separate claims.
