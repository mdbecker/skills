# Synthetic reliability-study transfer profile

This is a fictional mapping, not a claim about real observations. A target fixture
already contains `evidence/cohorts.json`, `templates/report.html`,
`scripts/assemble_report.py` and `scripts/check_report.py`. Those existing tools
are target-project dependencies, not bundled research execution tools.

Authority: cohort manifest and saved aggregate results; schema/derivation contract
overrides narrative shorthand. Cohort A uses a random service-day sample; cohort B
uses incident-enriched samples with a different fingerprint. Preserve each cohort's
identity, denominator, selection and uncertainty; do not pool or infer improvement.

Editable inputs: template and presentation sources. Output: `report.html`, using
the existing assembly command, with no new data collection or pipeline. Snapshot
evidence/schema/template hashes before rebuilding. Restricted raw incident logs
must not enter output; only permitted aggregates above the recorded suppression
threshold are displayed. Missing threshold or evidence blocks output rather than
inventing policy.

Acceptance: unchanged protected metrics for an editorial edit; a numerical
correction needs an explicit request plus saved corrected evidence. Check source
hashes, cohort labels, denominator/caveat links, offline/narrow/print behavior and
the existing checker. Failed assembly preserves the prior report or creation inputs.
