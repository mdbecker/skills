# Incidental-findings report profile

Authority: current README, REPORT_HANDOFF, source evidence, schema/Pydantic domains
and actual derivation code. Catalog shorthand does not override those definitions.

Build graph: saved notebook JSON/source literals, saved aggregate evidence,
schema/prompt, report template/helpers, canonical viewer and diagram sources/assets
feed `scripts/assemble_report.py`; `scripts/check_report.cjs` verifies generated
report behavior. Read assembler/dependency configuration before invoking tools.
Map the existing suitable Python environment, Node/Pydantic/viewer dependencies
and restricted atlas/manifest permission; missing dependencies block rebuild.
Never execute notebooks or retrieve the restricted inputs to fill gaps.

Editable surfaces: `scripts/report_template.html`, assembly/presentation helpers
and diagram sources. Generated report HTML is not the editing source. Preserve
markers, reconstructed-prompt hashes, asset hashes and provenance/disclosure checks.

Protected evidence: distinct source/cohort fingerprints, denominators, selection
methods, counts, saved derivations, uncertainty and comparison caveats. Do not pool
unmatched descriptive/atlas cohorts or treat count differences as improvement.
Disagreement-enriched subsets are not prevalence estimates. Obtain actual values
from saved authoritative artifacts; historical counts/dates are not defaults.

Privacy: restricted atlas may be read only by the established approved pipeline;
only whitelisted grouped geometry and aggregates enter output. No clinical records,
identifiers, private quotations or restricted assets in a delivered bundle/report.
Preserve suppression and aggregate allowlists. Scientific/clinical validity has
not been established by assembly or an unexecuted expert review.

Checks: existing report/asset/provenance checks plus actual desktop/narrow layouts,
cohort controls, links, expand/collapse, field search/reset, prompt copying, print
restoration and offline network behavior. No external fonts/scripts/analytics are
expected in the self-contained report. Preserve prior output on failed rebuild.
Missing historical artifacts and expert/browser checks remain explicit limits.
