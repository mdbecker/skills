# Agent-template reference profile

Authority: current template instructions, README, architecture, dev configuration
and deployment reporting contracts. Prefer its existing suitable repository-local
environment. Reference canonical check:

```sh
python3.12 -m pre_commit run --all-files --show-diff-on-failure
```

Hook installation is separate setup; do not substitute focused tests for required
full validation or authorize auto-fixes/installations through readiness inspection.
Protect model-driven tool selection, configuration, storage routing and job wiring
where affected. The reference prohibits default manual allowlists/deterministic
Python routing; that is not a universal design rule for other projects.

The deployment guide's smoke check is a deployed job, not only bundle validation.
This defines the boundary of reporting: it does not authorize deployment, job runs
or Databricks access. Exclude caches, local state and build artifacts. Map another
project's language/runtime/commands rather than transplant this example.
